# Changelog

All notable changes to the Compresr extension will be documented in this file.

## [0.1.0] - 2026-02-01

### Added
- Initial release
- Compress current markdown file with preview diff
- Compress all markdown files in workspace
- Model selection from API
- Configurable compression ratio (10% - 90%)
- Automatic backup creation (.bak files)
- Restore from backup functionality
- Quick Settings menu (Cmd+Shift+, / Ctrl+Shift+,)
- Context menu integration for file explorer
- Editor title bar button for markdown files
